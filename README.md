# 🏥 Hyper-Local Public Service & Health Connector

A web-based platform designed to help users access verified public service and health-related information in their local area.

## 📌 About the Project

The Hyper-Local Public Service & Health Connector provides users with easy access to public services, health information, emergency contacts, government schemes, local announcements, and nearby service centers.

The system is designed to make important public and health information easier to find and access.

## ✨ Features

- 🔐 User and agent login
- 🏛️ Government and public service information
- 🏥 Health-related information
- 📍 Nearby service centers using OpenStreetMap
- 🚨 Emergency contacts
- 📰 Local announcements
- 🔔 Notifications and health alerts
- 🌐 Multi-language support using Google Translate API
- 🎙️ Voice-based access
- 👨‍💼 Agent management of service information

## 🛠️ Technologies Used
